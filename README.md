# AI × Web3 School — Cohort 0

> Personal learning journal and proof-of-work for [AI × Web3 School](https://aiweb3.school/).

## 关于

[AI × Web3 School](https://aiweb3.school/) 是由 LXDAO 与 ETHPanda 共同发起的开源学习计划，面向 builders 系统学习 AI、区块链、智能合约、AI Agent 与去中心化 AI。

本仓库是我的个人学习记录仓库，包含：

- 每日学习笔记与打卡草稿
- 课程任务与任务证明 (Proof-of-Work)
- 实验与项目原型
- Handbook 反馈
- Hackathon 准备材料
- 作业提交
